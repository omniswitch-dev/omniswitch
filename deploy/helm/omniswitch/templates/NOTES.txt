{{- if eq (include "omniswitch.generateBootstrapKey" .) "true" }}
No bootstrap API key was supplied, so the chart generated one. Read it with:
  kubectl get secret -n {{ .Release.Namespace }} {{ include "omniswitch.secretName" . }} \
    -o jsonpath='{.data.OMNISWITCH_BOOTSTRAP_API_KEY}' | base64 -d
Use it to create named keys, then treat it like any other owner key.
Rendering with `helm template` (Argo CD, Flux post-rendering) creates a new key
on every render and rotates the owner key; set bootstrap.generate=false and
supply the key yourself with those tools.
